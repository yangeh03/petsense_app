# AI 运动日记

用户从「今日 → 今日记录」点击生成。服务端验证宠物归属，读取档案照和当天的有效动作观测，异步提交。档案照会缩至最长边 1600 px 并转为无原始元数据的 JPEG。步数采用 150 步／分钟的试点步频，由观测到的走动秒数估算。这个值未经项圈实机校准。

App 通过 `GET/POST /api/app/exercise-diaries/{pet_id}` 查看或提交任务。生成结果由服务端从 PetGIF 的鉴权海报接口读取，并保存在运行目录的 `diary-posters/`。App 通过 `GET /api/app/exercise-diaries/poster/{job_id}` 鉴权读取，保存或带入社区现有发布页。历史照片模板仍通过同一鉴权接口读取。

## 启用条件

- 用 `PETSENSE_PETGIF_DIARY_PET_ID` 设置专用于日记的 PetGIF 宠物 UUID。PetSense 的宠物档案无需绑定此 ID。
- 通过已有 `PETGIF_KEY_FILE` 提供服务端 AK。
- 用非个人测试照片核查该上游配置。提交后要能轮询状态、带 AK 读取图片，并确认照片和海报均无可匿名打开的静态地址。将两张不同宠物的照片交给同一 ID 时，分别核对海报是否采用对应照片中的宠物。
- 核查通过后在服务端设置 `PETSENSE_PETGIF_PRIVATE_DIARIES=1`。配置尚未齐备时，App 提交会收到暂未开放提示。已有日记可继续查看。

隔离测试覆盖档案照提交、同日去重、步数估算、私有海报读取及历史模板。生产验收还需确认目标 PetGIF 账号及实际私有存储配置。

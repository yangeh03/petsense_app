# 地图动作宠物标记

位置页复用今日页 `selectPetAvatar` 的动作选择：设备必须匹配，动作置信度至少 0.6；端侧结果优先，不预览、不猜测静止动作。动作新鲜度与 UWB 坐标新鲜度独立判断。

用户在 2026-11-27 明确选择“先只做地图接入，暂不处理 GIF”。直接复用今日页选择的原 GIF 地址，保留原背景、人物、动作和时序，不生成替代角色、不修改源素材。地图用约 40 屏幕点大小的原生 expo-image 动画替代圆点，缩放地图不会放大宠物；动画中心即定位坐标。Reanimated 继续在地图坐标中插值，保留凹边界约束、过期冻结和恢复时跳过跨期插值。

地图下方同时显示动作、区域和 XY 坐标。无可靠动作、无对应动画或加载失败时显示爪印；无可靠动作时明确标注“动作待识别”。定位失效时图标淡化并保留最后位置；减少动态效果设置不播放 GIF，并改用爪印（包括 Web）。

标记为圆形细边框，内部保留 3 屏幕点内边距，用 contain 显示原 GIF，避免身体被圆形边缘裁切。轮廓和 GIF 都以同一位置中心移动。

本功能不改变固件、服务端坐标或当前地图标定。客户端变更需要随 App 更新发布。原生真机及实地误差验收另行记录。

# UWB 定位边界与圆点动画

2026-11-26：功能分支实现；尚未部署或进行本轮真机验收。第一版地图绑定保持不变。

## 边界来源与坐标

使用已随点云建图、朝向调整和对齐结果发布的 `map.json.polygon`。这是当前地图坐标系中的场地外轮廓，不是图片外接矩形，也不把点云缺损填成可达区域。新地图仍走现有点云处理、人工预览确认和发布流程；轮廓与底图、基站和定位变换必须一同更新版本。此轮不新增家具分割、内部障碍洞或区域语义。

服务端保留测距滤波与三边解算，仅约束对外显示坐标：首次越界取最近边界点；连续移动沿上一显示点到新解算点检查线段，停在第一次离开轮廓的位置。即使两个端点都在凹形区域内，也不能直接穿过外部凹口。点可以沿边界移动或返回内部；无可达路线证据时不自动规划绕行路径。约束不是精度改善，地图或标定错误仍需人工纠正。

`position` 为约束后的地图坐标，新增兼容字段：`rawPosition` 为滤波测距三边解算后、位置平滑前的地图坐标；`unconstrainedPosition` 为位置平滑后、边界约束前的地图坐标；`boundary.constrained` 和 `boundary.correctionM` 记录是否修正及修正距离。`quality.insideMap`、残差和得分仍反映未约束结果，不因贴边而变成高质量。约束不反馈进测距或位置滤波器，不改固件上传数据。旧客户端忽略新增字段；新客户端可连接旧服务器并在动画层防越界。

## 动画与状态

实时地图仍只有一个当前位置圆点。Reanimated 在 UI 线程以线性动画连接显示位置与新目标，最长 850 ms 且不超过本次剩余有效时间；新测量从当前动画进度继续，不从上一测量终点重新出发。重复轮询不重启动画，不刷新测量期限，不插入轨迹样本。动画目标再次经过同一轮廓的线段检查，避免平滑过程中穿过凹口。

首次定位及断连恢复直接定位到有效目标；过期立即取消动画，冻结灰色最后显示点。地图版本、修订或设备变化重建圆点组件，不跨坐标系插值。尊重系统减少动态效果设置。动画只改善显示，不外推位置、不补演离线运动。

## 验证

覆盖首帧越界、边界滑动、凹角穿越、重复顶点、原始坐标及质量保留、公开接口诊断字段，以及动画中途重定向、重复轮询、过期冻结和恢复。客户端执行 lint、typecheck、format:check、全部单元测试；服务端执行全套测试。Windows 测试启动器将 Alembic 配置读取设为 UTF-8，以读取仓库既有中文配置；不修改产品编码逻辑。

本轮真机待验：沿墙移动和短时漂移、转角、断连恢复；手机上观察位置动画流畅度。第一版沿用旧基站标定，当前新场地不应直接套用它定位。

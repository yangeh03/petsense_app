# UWB 整合待办

## 当前确认的计算分工（2026-10-28）

当前开发统一采用 `ESP32 采集 → 4G/MQTT 回传 → 云端处理 → App 展示`。

- ESP32 使用 `firmware/petsense_esp32`，在同一固件中采集 IMU 和 BU03 UWB 测距，负责协议解析、基础有效性/新鲜度判断、缓存与上报，不承担本轮动作识别模型推理或二维定位解算。
- 云端负责 IMU 动作识别、UWB 测距滤波与定位解算、质量/过期判断，并通过已鉴权接口向 App 提供结果。
- App 负责显示动作结果、实际户型底图、定位与轨迹，以及地图拖动/缩放，不在手机中重算定位。
- 点云建图使用独立离线工具，生成版本化地图资产；App 上传点云和在线建图任务不在本轮范围。

仓库中的 `edge_firmware` 是另一套端侧模型实验固件，保留原代码，但其模型部署和 UWB 移植不属于当前待办，也不是当前云端处理方案的发布前置条件。

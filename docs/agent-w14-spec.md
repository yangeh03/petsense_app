# W14 体验合流

2026-11-24。状态：**已定稿**（§3 决策经负责人确认），实施与验收进行中。

复用 W01–W12 已合入的能力（main `1465714`，2026-11-24 已部署生产并 OTA）。W13 推送未合入，不在本包范围，见 §4。

## 1. 目标

W01–W12 是分开发、分头验收的。本包把它们放进**同一次连续使用**里检查：主人从问一句实时状态开始，补资料、发照片、查知识、看主动发现、确认委托、收到回信、下钻依据、触发动作，过几天再回来找——全程在同一只宠物、同一条会话里完成，返回、话题、草稿都不丢。

工作包给定的验收口径三条：完整场景连续完成；情绪表达来自真实经历与状态；返回、主题、草稿不丢失。

## 2. 完整场景主线

| 步 | 主人做什么 | 经过的能力 | 应当看到 |
| --- | --- | --- | --- |
| S1 | 问实时状态 | W01/W02 | 零工具或单工具作答，数值与今日页一致；离线或过期如实说明 |
| S2 | 补资料 | W03 | 明确指令直写并回显；模糊信息出确认卡；档案页与之后的对话是同一版本 |

| S5 | 看主动发现 | W09/W11/W12 | 今日预览或铃铛定位到那条消息；「为什么提醒我」引用依据；证据展开数值一致；已读同步 |

## 4. 边界

**不做：**

- 不新增工具、运行形态、持久对象、接口或迁移。本包没有接入点声明，只动展示与交互。
- 不做 W13 推送及其原生构建。W13 合入后，通知点击定位的走查在 W13 包内补。
- 不做区域语义（定位侧未交付）。
- 不做真机验收，属于 W13 与 W15。
- 不调整人格与话题策略的提示词基调。只有串联中证实了的缺陷才改服务端，且改后跑行为评测回归。
- Android 不在范围；Web 只做构建与发送冒烟。

**生产上的操作边界：** 只发送验收消息、确认委托、生成运动日记、保存私有社区草稿，都可以回看且不外发。不确认任何档案修改，不改真实资料，不绑定设备。档案修改的确认卡在生产上只看到待确认为止，然后选「不要」。

**与在途工作的边界：** 分支 `fix/agent-review-recap-and-degraded-letter`（另一会话进行中，未提交）在改回顾提示措辞、E51（改到多提醒档）与新增 E73、降级回信带核对结果的文案，涉及 `care_jobs.py`、`change.py`、`tasks.py`、`task-result-card.tsx`、`agent-change.ts` 与行为评测。本包不改这些文件；发现相关问题只记录，等该分支合入后变基再处理。

**行为评测编号：** 本包若新增场景，从 E80 起；E74–E79 留给在途分支。

中断前的走查已修掉 K1/K2/K4/K5/K12 与首开回滚（F1）。**本轮在 V8 对比度走查中又挖出六类同源缺陷**，
根因一致：品牌色与语义色被当文字色用，或主按钮仍压白字。

| 编号 | 现象 | 修法 |
| --- | --- | --- |
| N1 | 主按钮与分段控件选中态仍是白字压珊瑚橙（社区页「发现/关注」、附近页半径与分区、社区搜索「综合/帖子/宠友/地点」、登录主按钮、关注列表按钮、评论发送按钮） | 统一改用主题已有的 `theme.onTint`。珊瑚橙实底压白字：浅色 2.68:1、深色 2.22:1 → 改后 4.90:1 / 8.39:1 |
| N2 | 全 App 78 处把品牌橙当文字色（浅色下压白底 2.68:1） | 文字改走 `theme.tintForeground`（#9A4423，压白底 6.51:1）。深色主题下 `tintForeground` 与 `tint` 同值，视觉零变化；实底按钮文字仍用 `onTint`，两者语义不同 |
| N3 | 语义色当文字色：`warning` 2.19:1、`info` 3.23:1、`online` 2.9:1 | 文字改走已有的 `warningForeground` / `onlineForeground`，并新增 `infoForeground`（浅色 #2F5FBF，5.98:1；深色沿用 #7FA8F2） |
| N4 | 徽标红底白字 3.91:1（浅）/ 2.90:1（深）；浅色 `danger` 作错误文字压白卡同样 3.91:1 | 浅色 `danger` 加深为 #C62B2B（两种用法均 5.55:1）；新增 `onDanger` token（浅色白字、深色深字），徽标文字改用它 |
| N5 | 深色 `danger` 压 `tintBackground` 只有 4.41:1 | 深色 `danger` 由 #FF6369 调为 #FF7176（4.80:1） |
| N6 | 页面/组件里写死颜色 | `themed-text.tsx` 的 `linkPrimary`（#3c87f7，无任何页面使用）删除；其余为生成资源与数据驱动色（`generated/leaflet-assets.ts`、`floor-plan.tsx`、`animated-icon.tsx` 渐变），属既有取舍，不在文字 token 口径内 |

每类修复都补了定点断言：`app/tools/theme-contrast.test.cjs` 现在校验正文/次级文字压三种底色、
`onTint` 压 `tint`、`tintForeground`/`warningForeground`/`onlineForeground`/`infoForeground`/`danger`
压四种底色、`onDanger` 压 `danger`，两种主题各跑一遍。

「发布故事」「重新尝试」「查看站内收件箱」「回到原会话」「想调整？」等链接由浅珊瑚橙变为 #9A4423。

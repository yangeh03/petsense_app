# W14 体验合流

2026-11-24。状态：**已定稿**（§3 决策经负责人确认），实施与验收进行中。

复用 W01–W12 已合入的能力（main `1465714`，2026-11-24 已部署生产并 OTA）。W13 推送未合入，不在本包范围，见 §4。

## 1. 目标

W01–W12 是分开发、分头验收的。本包把它们放进**同一次连续使用**里检查：主人从问一句实时状态开始，补资料、发照片、查知识、看主动发现、确认委托、收到回信、下钻依据、触发动作，过几天再回来找——全程在同一只宠物、同一条会话里完成，返回、话题、草稿都不丢。

工作包给定的验收口径三条：完整场景连续完成；情绪表达来自真实经历与状态；返回、主题、草稿不丢失。

## 2. 完整场景主线

| 步 | 主人做什么 | 经过的能力 | 应当看到 |
| --- | --- | --- | --- |
| S1 | 问实时状态 | W01/W02 | 零工具或单工具作答，数值与今日页一致；离线或过期如实说明 |
| S2 | 补资料 | W03 | 明确指令直写并回显；模糊信息出确认卡；档案页与之后的对话是同一版本 |
| S3 | 发照片 | W07 | 上传中不可发；带图回合；灯箱可开合；重进会话图片仍在 |
| S4 | 问养宠知识 | W06 | 结论、来源卡与核对时间；系统浏览器可打开；常识问题不搜索 |
| S5 | 看主动发现 | W09/W11/W12 | 今日预览或铃铛定位到那条消息；「为什么提醒我」引用依据；证据展开数值一致；已读同步 |
| S6 | 说一句委托 | W08/W11 | 确认卡列出计划全文与基线口径；确认后委托簿显示「正在留意」；未确认不启动 |
| S7 | 收到回信 | W08/W11 | 回信卡（提醒、回信或降级回信）；冻结证据可展开；委托簿与收件箱同步 |
| S8 | 下钻依据再回来 | W02/W12 与记录页 | 来源卡展开数据，进入记录页「引用时段」，返回伙伴页后草稿、滚动位置、话题不丢 |
| S9 | 触发动作 | W10 | 日记结果卡可进日记详情；草稿结果卡可到发布页恢复；录音如实说明未开放 |
| S10 | 过几天找回 | W04/W08/W12 | 新回合经记忆找回之前讲的事；委托簿与收件箱可回看历史，不生成新回合 |

贯穿 S1–S10 一并检查：双人格节奏、学习期与等待、无数据、失败时的表达、键盘与长消息、原功能不受影响。

## 4. 边界

**不做：**

- 不新增工具、运行形态、持久对象、接口或迁移。本包没有接入点声明，只动展示与交互。
- 不做 W13 推送及其原生构建。W13 合入后，通知点击定位的走查在 W13 包内补。
- 不做区域语义（定位侧未交付）。
- 不做真机验收，属于 W13 与 W15。
- 不调整人格与话题策略的提示词基调。只有串联中证实了的缺陷才改服务端，且改后跑行为评测回归。
- Android 不在范围；Web 只做构建与发送冒烟。

**生产上的操作边界：** 只发送验收消息、确认委托、生成运动日记、保存私有社区草稿，都可以回看且不外发。不确认任何档案修改，不改真实资料，不绑定设备。档案修改的确认卡在生产上只看到待确认为止，然后选「不要」。

**与在途工作的边界：** 分支 `fix/agent-review-recap-and-degraded-letter`（另一会话进行中，未提交）在改回顾提示措辞、E51（改到多提醒档）与新增 E73、降级回信带核对结果的文案，涉及 `care_jobs.py`、`change.py`、`tasks.py`、`task-result-card.tsx`、`agent-change.ts` 与行为评测。本包不改这些文件；发现相关问题只记录，等该分支合入后变基再处理。

**行为评测编号：** 本包若新增场景，从 E80 起；E74–E79 留给在途分支。

6. **回写**：本文件 §8、AGENTS.md、截图索引 `docs/reviews/2026-11-24-agent-w14/`。

| 编号 | 场景 | 通过条件 |

| W14-A1 | S1–S10 连续走完 | 同一会话、同一宠物，中途不靠接口造数续接；每步的「应当看到」成立 |

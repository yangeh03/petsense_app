## 比较、交付与委托

- 复用 W05 `read_baseline` 的观测与参照规则。动作走动秒数、声音事件次数维度独立。四个粗时段沿用上海时间和已有覆盖下限，日期只使用目标日期之前的基线样本。区分维度学习、时段样本不足、观测时段未结束、当前覆盖不足和有效但处于范围内。边界值等于 p10 或 p90 时视为范围内。
- W09 回顾组装并校验实际时段证据。只有通过 D2 的候选可被模型选为个人变化主题。模型输出以稳定证据引用锚定，服务端校验引用与时段、数值和方向是否相符。失败或证据不足时回退绝对事实描述，沿用 W09 的主动程度、时段去重、任务队列与主题生命周期。硬件事件权限不扩大。涉及工具契约的改动先更新 P00，再更新注册表。
- 每条个人变化或委托交付的证据固化到现有持久对象，包含目标日期与时段边界、动作或声音、单位、覆盖、样本量、样本起止日期、版本、修订、p10/p50/p90、实际值及方向；来源入口可下钻到对应记录。旧内容保持兼容，读取时无需重算比较，也不调用模型。不得使用换绑前的设备或旧模型版本补齐新版本。
- 基线就绪的相对委托沿用显式确认。未就绪的委托在客户端提交用户实际选择，服务端确认协议同时验证版本、选项、归属和原截止时间。等待策略从确认后且就绪后开始计入有效比较，暂停区间排除，到期仍未就绪则交付覆盖与学习状态。事实策略沿用同一已确认窗口，只给绝对事实，不把原比较目标当作达成。已有计划、旧客户端和旧候选沿用兼容解析；缺少明确选择的新版候选不静默生效。

## 比较、交付与委托

- 复用 W05 `read_baseline` 的观测与参照规则。动作走动秒数、声音事件次数维度独立。四个粗时段沿用上海时间和已有覆盖下限，日期只使用目标日期之前的基线样本。区分维度学习、时段样本不足、观测时段未结束、当前覆盖不足和有效但处于范围内。边界值等于 p10 或 p90 时视为范围内。
- W09 回顾组装并校验实际时段证据。只有通过 D2 的候选可被模型选为个人变化主题。模型输出以稳定证据引用锚定，服务端校验引用与时段、数值和方向是否相符。失败或证据不足时回退绝对事实描述，沿用 W09 的主动程度、时段去重、任务队列与主题生命周期。硬件事件权限不扩大。涉及工具契约的改动先更新 P00，再更新注册表。
- 每条个人变化或委托交付的证据固化到现有持久对象，包含目标日期与时段边界、动作或声音、单位、覆盖、样本量、样本起止日期、版本、修订、p10/p50/p90、实际值及方向；来源入口可下钻到对应记录。旧内容保持兼容，读取时无需重算比较，也不调用模型。不得使用换绑前的设备或旧模型版本补齐新版本。
- 基线就绪的相对委托沿用显式确认。未就绪的委托在客户端提交用户实际选择，服务端确认协议同时验证版本、选项、归属和原截止时间。等待策略从确认后且就绪后开始计入有效比较，暂停区间排除，到期仍未就绪则交付覆盖与学习状态。事实策略沿用同一已确认窗口，只给绝对事实，不把原比较目标当作达成。已有计划、旧客户端和旧候选沿用兼容解析；缺少明确选择的新版候选不静默生效。

### 6.1 交付面

- **服务端新模块 `server/petsense/agent/change.py`**：比较单元统一为「维度 × 日期 × 粗时段」（D2）。`compare_day()` 输出候选记录（`evidenceId=维度:日期:时段`），并如实区分五类不可比原因：维度学习（`baseline_learning`）、时段样本不足（`slot_sample_insufficient`）、观测时段未结束（`slot_not_ended`）、当前覆盖不足（`coverage_insufficient`）、有效但处于范围内（`within`）；边界值等于 p10 或 p90 一律视为范围内。目标日期自身不入样本（只取该日期之前的基线有效日）。`freeze()` 冻结 D6 证据：样本窗口、基线版本与修订号、p10/p50/p90、实际值、覆盖与方向。`slot_observations()` 按有效观察窗口汇总逐日逐时段实际值与覆盖。`claims_personal_change()` 为服务端兜底：有个人比较口播但无合格证据时拒绝该结论。

- **回顾侧（W09 合流）**：`care_jobs.review_facts()` 增 `personalChange` 段（`review_candidates` 先惰性物化基线）。模型发现新增 `category=personal_change`，必须带 `evidenceId`；服务端校验引用存在、方向相符、数值相符，任一不符即拒绝该发现。没有任何合格候选时，模型正文出现「比平时/高于平时」等比较口播即触发降级（`personal_change_without_evidence`）并回退绝对事实描述。交付新增 `personal_change` 块（冻结证据）与时段来源下钻；主题依据内嵌冻结证据。D4：日回顾按对应粗时段比较；周回顾只汇总本周已结束且可比的日内时段，不作整周总量比较。同锚点（`change:<evidenceId>`）跨日/周回顾合并，不重复开题。

### 8.1 回顾（E51）

- **规则不变**：标准档只交付模型标为 high 的回顾（W09 D2）；学习期不提「比平时」（W05/W09），服务端仍以事实摘要兜底。

**需要知道的结果**：现网约一半数据日会收到的那条「观察小结」，是模型违规的副产品——写了不该写的那句话，程序才把正文换成摘要，而写这句话的那几次恰好被标成「值得发」。说明书改掉后，这个副产品基本消失：**标准档下，普通数据日大多不再发回顾**（本组观测 8 次里 1 次发，是模型自己的诚实表达而非替换摘要）；想每天看回顾要开「多提醒」档（E51 在该档 8/8 交付）。这与 W09 D2 的原文一致。如果希望标准档下每个有数据的日子也发一条，需要在说明书里再加一句，属于另一条产品规则。

### 8.5 断言词表的两处补充（验证过程中发现）

否定词表补「不做 / 不下 / 不推断 / 不判断 / 不臆测 / 不是」：真实模型原句「所以不做异常判断」「其余时段是数据缺口，不是活动减少」先后被判成断言。修正后用 7 条真实/构造句核对：否定式说明不算断言，真正肯定的断言（「今天下午活动减少了」「不是活动减少，而是明显活动减少」的后半分句）仍被拦下。

# 恢复宠物形象为核心的 Dashboard

用户要求：大体沿用原 dashboard，中央保留宠物动画形象或头像；端侧上报动作后在 App 切换对应的预设动作。沿用此前无需逐步确认的授权，在现有 codex/pet-data-experience worktree 修正。

布局恢复为日期与通知、居中问候、中央宠物形象和状态、三项体征、今日记录与可展开趋势。移除占据主视觉的文字状态卡及右上角小头像。点中央形象编辑宠物档案；点连接状态查看诊断。声音只作小提示，不遮挡动作形象。

复用已有 PetGIF behaviors 素材合同，而非另外生成形象。edge standing/sitting/lying down/walking 严格映射 stand/sit/lie_down/walk；已支持的旧服务端模型结果仅作兼容。新帧、绑定设备、置信度达0.6才播放对应动画；edge unknown/warming_up 或低置信度不回退为其他动作，不使用时间/IMU猜睡眠。health.valid=false 不影响独立的动作模型结果。静态回退优先用户头像、角色卡、emoji；缺少对应动画不得随机播放另一动作。GIF加载失败回退静态且保留动作文字。切动作时重置图像，防止旧动作驻留。

方案比较：仅把上一版头像放大不足以恢复原布局；完全回滚会丢失声音、趋势和持久化修正；采用恢复原构图、保留新数据链路的方式。现有预设素材按宠物 PetGIF 绑定提供，素材没有生成的动作只呈现识别文字和静态头像，不声明素材已经齐备。

不变更后台、固件、持久化及资料 API，不部署。验收覆盖四动作映射、低置信度/断流/设备不符/素材缺失/错误素材归属，客户端全部检查以及 computer use 手机宽度视觉验收。

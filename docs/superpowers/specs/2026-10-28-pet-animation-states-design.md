# 首页宠物动画状态

用户授权按实际用途实现互动／吠叫状态，并允许省略没有必要的 `/run` 功能。

## 取舍

- 采用已有状态素材：不产生生成费用，延续当前首页和声音识别链路。
- 不开放 `/run`：该接口用于重新生成视频和 GIF，会修改共享模板并产生费用，适合素材维护而非普通用户重载图片。目前没有个人生成素材的产品入口，也不建立额外的维护界面。

## 行为

- 已确定当前动作且有同一角色、同一姿态的 interaction GIF 时，显示“动画互动”。点击后短暂播放，四秒后恢复普通动作。保留离线点击切换动作的现有操作，离线动画明确标为动作预览。
- 只有新鲜、属于当前设备、置信度至少 0.6 的 bark 识别结果，才能触发对应姿态的 barking GIF。嚎叫、呜咽、未知声音不使用吠叫动画。动作不确定时保持静态展示。
- 吠叫优先于手动互动。状态素材缺失或加载失败时回退到当前角色的同姿态普通动画，不借用其他角色的状态素材。
- 切换宠物或动画身份时重置预览、互动和媒体状态。已有图片重试继续只重新加载媒体。

## 验证

扩展现有选择器测试，覆盖优先级、设备归属、新鲜度、置信度、缺失／失败素材、角色一致性和离线预览；运行客户端 lint、typecheck、format:check、完整测试。遵循 Expo SDK 57 文档，复用 expo-image，无新增依赖或服务端变更。

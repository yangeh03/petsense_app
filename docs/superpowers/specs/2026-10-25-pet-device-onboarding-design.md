# 宠物建档、设备绑定与首页状态

用户要求直接执行，通过 iPhone Expo Go computer use 检查并修复建档、配对和首页展示。设备编码示例为 petsense-esp32-001。当前服务端限定一个账号一只宠物、一个设备。

## 现场发现
- 首页添加宠物进入 create 默认发帖模式；设备绑定藏在我的页。
- 建档同时包含照片、长耗时 AI 和设备编码，创建成功后的 AI 失败被当成整体失败。
- 已认领设备后再创建宠物可能没有实际关联；重复认领没有修复关联。
- 首页没有区分未绑定、离线、无效传感器与有效数据，主指标默认折叠。
- 已实际上传公开测试狗照片调用形象 API：2.7 秒返回 502，上游创建 HTTP 404。此次跳过 AI 接入，保留已有服务代码。

## 方案与决定
采用独立 setup 路由，按档案→设备→完成推进，主页和我的共用。继续扩展 create 会保留发帖与初始化混杂的问题；一次大表单没有解决失败重试和下一步引导，因此不用这两种方式。

档案只要求名字和物种，头像与品种可选。保存立即持久化，不依赖 AI；配对失败只重试配对。设备由用户手动输入，不自动认领测试编码。支持稍后绑定和再次进入继续。绑定完成明确告知等待真实数据、返回首页。已有档案不提供重复创建入口。

首页展示真实绑定设备的三项主指标，区分实时、最近记录、设备离线和等待有效采样；无效或过期数据不冒充实时。显示更新时间、电量（0% 合法）、连接引导与重试。历史趋势有明确历史含义。保留数据真实性、归属过滤和现有主题。

## 验收
用 computer use 验证入口、建档、错误设备编码重试、绑定 petsense-esp32-001、返回首页。离线时保留诚实空态，不伪造帧。客户端检查及服务端隔离测试通过。

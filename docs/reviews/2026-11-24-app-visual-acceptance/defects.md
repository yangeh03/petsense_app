## D-01 · P1 · 伙伴会话回合列表出现重复 React key（已修）

- **现象**：伙伴页渲染时 React 报 `Encountered two children with the same key`，键值形如
  `.3:$care=2review=2daily=21=22026-11-23`；组件栈指向 `app/src/app/(tabs)/agent.tsx:628`
  的 `key={turn.requestId || turn.id}`。用户侧表现是聊天气泡可能被丢弃或错位复用。
- **根因**：渲染键取 `requestId || id`，而客户端回合列表只按 **id** 去重，**不校验 requestId**：
  - `services/agent-chat-turns.ts` 的 `mergeServerTurns` 只用 `turn.id < first` 判断保留，
    同 id 之外不校验 requestId；`reconcileTurn` 只移除「本地乐观回合」，
    服务端回合之间同 requestId 不会被合并；
  - `stores/agent-chat.ts` 的 `setTurns`（快照恢复路径，`hooks/use-agent-chat.ts:173`）
    直接整体写入快照回合，不做唯一性校验；
  - 服务端有 `UniqueConstraint('pet_id','request_id')`（`server/petsense/db/models/agent.py:27`），
    **重复只可能出在客户端状态**（快照是上一版客户端写下的，可能带旧格式 requestId 或重复条目）。
- **修复**：新增 `dedupeTurns()`（`app/src/services/agent-chat-turns.ts`），
  按 **id + requestId** 双重收敛，「服务端回合优先、本地乐观回合被替换、同类取较新」；
  接入 `setTurns` / `syncTurns` / `applyTurn` / `prependOlder` 四条写入路径。
- **复验**：向 AsyncStorage 注入同 requestId 的两条回合后重载，重复键告警消失；
  `tools/agent-chat-turns.test.cjs` 新增 5 条回归用例（合计 16/16 通过）。
- **遗留**：旧版客户端写入的历史快照本身仍带旧格式 requestId，本轮未做迁移清理；
  下次升级时该快照会被新写入的干净快照覆盖。

## D-02 · P1 · 今日页 /「我的」页滚动内容与系统时钟、灵动岛重叠（已修）

- **现象**：这两页没有固定顶部栏，内容滚动后直接进入状态栏区：
  今日页「最近更新 01:22」与系统时间 `00:07` 叠在一起；「我的」页「暂未在线 · 电量 0%」被灵动岛压住一半。
  有顶栏的伙伴页、社区页无此问题。
- **修复**：新增 `app/src/components/status-bar-scrim.tsx`，在页面顶层盖一层高度为 `insets.top`、
  颜色为 `theme.background` 的遮挡层（不拦截触摸），今日页与「我的」页挂载。
- **复验**：`fix-b1-today-scrolled-light.jpg`、`fix-b5-profile-scrolled-light.jpg`——时钟完整可读，内容在状态栏边界处干净裁切。
- **备注**：经复核，位置页底部说明文字**不是**被标签栏遮挡——滚到底后内容正常避开标签栏
  （`paddingBottom: BottomTabInset + insets.bottom + 28` 生效），初看时只是折叠线以下。

## D-03 · P1 · 连接状态圆点写死 7 个颜色，与主题语义色不一致（已修）

- **现象**：`app/src/components/live/connection-dot.tsx` 里 `COLORS` 写死 7 个色值，
  其中绿色有两套（`#34C77B` 与主题 `online #31A66D`）、灰色有两套（`#9AA0A6` / `#8E9AAF`），
  且都是固定值，**深色模式下不随主题变化**。违反 AGENTS.md「颜色不要在页面里写死」。
- **修复**：改为按 `TelemetryDisplayState` 取主题语义色
  （streaming→`online`，connecting/reconnecting→`warning`，replaying→`info`，其余→`textSecondary`）。
- **复验**：typecheck / lint / test 通过；该点为 8pt 小元素，未单独截图取证。

## D-10 · P2 · 多行状态文本用字面换行符排版（待修）

- **现象**：`app/src/app/collect.tsx` 与 `app/src/app/uwb-setup.tsx` 的状态/坐标块用 `\n` 拼字符串，
  例如 `项圈时钟 等待校准 · SD 未就绪 · 未采集 · 落盘 0 条\n缺失时隙 0 · 队列丢样 0 · 写入错误 0\nSD 剩余 / 总容量：等待设备在线`，

## D-18 · P2 · 排版体系整体失控（待修，需专项）

代码级量化（`app/src` 全量统计）：

| 指标 | 实测 | 说明 |
|---|---|---|
| 不同 `fontSize` 取值 | **21 种**（10/11/12/14/15/16/17/18/20/22/24/26/28/32/34/40/42/48/54/62 …） | `ThemedText` 只提供 12/14/16/48 六档 token |

| `fontWeight` 取值 | 仅 700 / 600 / 400 | token 里定义的 500 几乎没被使用，层级靠「加粗/不加粗」区分 |

  `letterSpacing` 只在中文小字（12–13pt）与全大写标签上按需加 0.2–0.5。

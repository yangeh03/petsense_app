## 2. 判定方式

沿用 AGENTS.md「功能与视觉是两条验收通道，互不替代」：

- **功能通道**：AX 无障碍树（元素存在性、坐标、层级、可点性）+ 接口/服务端状态
- **视觉通道**：每页浅色/深色截图逐张读图判读（布局层级、间距、配色语义、遮挡、截断）+ 必要时像素测量

每条结论都标注走了哪条通道；只做了功能验证的条目明确写「仅功能通道」。

## 5. 未覆盖与如实标注的边界

- **真机与硬件**：项圈 GNSS 定位、UWB 实机标定闭环、远程录音、原生推送（APNs 票据）均未验证，本轮为模拟器级。
  通知推送页在 Expo Go 下前端显示「推送暂未开放」，Expo Go 自 SDK 53 起不再支持推送注册（Metro 日志有对应 WARN）；
  生产侧推送已于 2026-11-23 放行，因此该文案是 **Expo Go 宿主限制**，不是生产功能缺失。
- **故事详情页**（`story.tsx`）未进入：生产账号无可用故事数据，且按 AGENTS.md 不在生产创建公开内容。
  发布故事页的表单与入口已验。
- **iPad**：iPad Pro 11/13 (M5) 模拟器已安装但本轮未开机，顶部标签栏布局未验。
- **深色模式**：逐页已采双主题，但多数页面只对首屏做深色判读；长列表滚动后的深色表现未逐屏看。
- **原生 dev client**：不可用（dev server 固化 `localhost:8081`），故未在原生壳内复核。
  Expo Go 与原生壳的差异主要是原生通知/相册权限与原生 Tabs 的实现细节，页面视觉结论按 Expo Go 记录。
- **位置页 GNSS 分支**：室外视图的卫星定位需真机项圈，本轮只验到「等待项圈更新 GPS」的等待态与文案。

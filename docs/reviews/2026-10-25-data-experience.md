# 数据体验重设计验收记录

日期：2026-10-25。分支：`codex/pet-data-experience`。隔离 worktree 完成，无生产部署、固件修改或真实宠物档案写入。

## 产品变化

首页以当前状态、今日观测与声音事件为主线。连接状态收为可点击的一行；测量说明、声音详情、历史趋势及工程诊断逐层展开，触屏无需依赖 hover。趋势显示真实有效采样的加权均值与极值，不跨缺测连线，不把微小变化夸大为全高波动。在线但模型准备中、体征无效与断连分别表达，缺失数据不补成正常值。

声音识别保留端侧 bark/howl/whine；时间线只列声音片段，whine 标实验性，不声称片段数等于单声次数。动作仅使用端侧支持类别，不将静止等同睡眠。资料编辑以服务端宠物记录为权威；位置页撤下没有坐标来源的演示户型。

产品统计独立于原始数据环冲持久化，保留90天。账号、当前设备、认领时间隔离；同一分钟换绑亦不共享桶。重复、迟到、旧 boot 帧不参与广播或累计；重启、断连和无效测量不制造连续数据。

# 中央宠物形象 Dashboard 修正验收

用户反馈：上一版改变原 dashboard 构图过大，失去以实时动作驱动中央动漫宠物的核心设计。现恢复日期/问候、中央圆形宠物形象与动作徽标、紧凑连接提示、体征及下方记录/趋势。保留前一版的数据持久化、趋势口径和资料同步修复。

## 动作与素材合同

edge standing → stand、sitting → sit、lying down → lie_down、walking → walk，播放当前宠物绑定的 PetGIF behaviors 对应 gifUrl。动画地址保持不变时不因每秒遥测或15秒刷新而重挂载；动作改变更换图片 identity，避免展示上一个动作。

旧模型兼容只使用明确且置信度不低于0.6的上报结果。移除旧 hook 的 IMU分档、白天站立和夜间睡眠猜测。当前端侧 unknown/warming_up/低置信度不能借旧云端结果覆盖。动作与 health.valid 独立；失联/其他设备/未绑定不播放动作动画。

优先匹配动作GIF，否则依次显示用户头像、自己角色卡、emoji。素材缺失或加载失败仍保留实际识别的动作文字。声音作为小提示，和动作独立。未新增或生成一套宠物动画素材，素材使用现有PetGIF绑定；没有的动作不冒充已准备完成。

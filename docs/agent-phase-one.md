# Agent 第一阶段：实现与验证

阶段范围：P01–P06 的首条可运行切片。代码位于 `codex/agent-phase-one`；尚未部署或完成原生设备验收。

## 接口与持久化

- `GET /api/app/agent/pets/<id>/observations?start=&end=`：带时区时间、左闭右开，最多90天。按用户和本宠当前设备查询分钟统计、声音事件、有效体征；无区域语义时明确 unavailable。分钟粒度统计不能代表窗口内逐秒精确值。
- `GET /api/app/agent/pets/<id>/turns?before=`：每次40个回合、按ID稳定排序；保留主人原话、角色指向、实际发言角色、回复、主题/回复关联、已读状态和真实工具来源。
- `POST` 同一路径：`text, requestId, target(auto/pet/assistant), topicId?, replyTo?`。同键同内容返回已有回合，同键不同内容409。引用必须属于该宠。
- Alembic `0008` 增加 `agent_turns`、`agent_learning_days`，分钟记录保存来源版本与声音覆盖时长。学习覆盖随有效观测事务累计，重复/迟到帧不重复累计。进程中断留下的 pending 回合，五分钟后读取时标为失败，可重新发送。

## 模型与执行

读取服务端环境 `MINIMAX_API_KEY`，或由 `MINIMAX_API_KEY_FILE` 指定的外部文件；模型默认为 `MiniMax-M3.1-Flash`，Base 默认为国内 `https://api.minimaxi.com/v1`，可分别用 `MINIMAX_MODEL`、`MINIMAX_BASE_URL` 覆盖。凭据不进入 App、源码或文档。

先由模型判断话题范围和主回应角色；无关请求不进入数据工具，模糊请求澄清。允许的问题最多执行两轮、每轮最多四次只读观测查询；保留 MiniMax 工具调用的推理字段。流式文字每半秒最多保存一次，App 在生成期间轮询读取，完成后读取最终结果；当前不是 App 直连 SSE。

目前每回合生成一位主要角色的回复；主人可以明确指向爱宠/助手。资料写入、联网搜索、委托、成熟个人比较均不开放，不宣称已经保存或执行。

## App

导航为今日、位置、伙伴、社区、我的；记录迁至根 Stack，保留 `/records`。伙伴支持单输入区、角色指向、历史、主题聚焦、失败后重发；发送网络失败复用请求键。生成中的原话和部分回复从服务端恢复。草稿、主题、已加载历史和滚动位置在当前 App 进程中按用户保存，聚焦会话时更新服务端已读状态。

只有真实工具调用产生来源链接；记录页展示引用窗口的覆盖和走动量，原有日/周/月总览保留。返回使用 Stack；登录用户切换时伙伴状态重新挂载，避免显示前一账号的会话。

认识进度按动作/声音、设备、模型版本和日期持久累计，6小时且跨两个6小时时段才算有效日。分钟记录保留来源版本，版本变化不复用旧进度，缺少版本的历史不直接计入。区域等待语义接入；个人范围和基线快照由 P10 实现，当前不代表完整个人基线已建立。

## 验证边界

隔离数据库测试覆盖范围和设备隔离、消息去重、同键冲突、无关请求不调用工具、失败保留原话、过期 pending 恢复、非法时间与引用。真实模型连通、角色与工具调用另有联调证据；隔离数据库中的测试数据不是实机采集验收证据。

尚需原生端/浏览器交互验收，以及真实设备历史的全链路验证；未验证内容不作为完成结论。此文档随本阶段联调补充实际结果。

## 本轮实际验证结果

- 服务端全量 `PETSENSE_MQTT_DISABLED=1 python -m unittest discover -s server/tests`：208 项通过。
- App lint、typecheck、format:check、86 项客户端测试及 Web export 通过（最终检查结果以交付说明为准）。
- 国内 MiniMax 端点 + M3.1-Flash 已真实连通；隔离空数据库内，历史问答调用观测工具并返回一个可追溯来源，没有把无数据写为正常；宠物商城代码请求在工具之前拒绝。
- 浏览器隔离账号已走通登录、伙伴问答、来源记录窗口和返回；聚焦主题与未发送草稿在往返后保留。页面观察到逐步加载和最终回复，未将此视为原生流式表现验收。
- 尚未验收真实项圈历史、iOS/Android 交互和 App 图片输入。阶段 1 的主要对话链路和版本化学习累计已接通；缺少上述实机证据，不能等同于全平台与真实硬件的完整验收。

本地开发可在 server/ 下设置 `MINIMAX_API_KEY_FILE` 为仓库外凭据文件，配合 `PETSENSE_MQTT_DISABLED=1 python wsgi.py` 运行；App 的 `EXPO_PUBLIC_API_BASE_URL` 指向对应服务。部署时先升级兼容后端，再开放新客户端入口。

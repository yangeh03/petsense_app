# UWB 实测后的后续工作

记录日期：2026-11-18。状态：待开发，本次仅记录需求。

## 本轮实测结论

用户反馈当前新场地实时定位测试完成，没有问题。本轮采用用户确认的非镜像手动对齐方案，俯视底图顺时针摆正约 3°；正式客户端实时地图仅显示当前位置圆点。

这是用户对本次场景的实测反馈，不等于已完成量化精度测评、自动对齐验收或其他场地验收。地图边界约束、位置动画、区域语义及卡通底图均未因本次测试自动视为已实现。

## 1. 从点云设置定位边界

- 从点云提取并确认场地边界，限制显示的定位点移出边界。
- 边界必须与当前底图、基站、定位点使用同一坐标系和地图版本。
- 保留原始解算坐标与质量信息，明确记录约束后的位置，便于诊断漂移；不能把点云缺损直接判为可达区域。
- 验收：靠近边缘、短时漂移及重新上线时，显示点保持在确认边界内，行为稳定；不因约束把点跳到另一侧区域。

## 2. 实时位置平滑移动

- 新坐标到达时，让当前位置圆点平滑移动到目标位置，消除逐帧跳变或闪烁。
- 动画只改善显示，不伪造新测量，不恢复历史轨迹线。
- 连续更新、短时断连、过期位置和恢复定位需有明确处理，避免动画继续表现为实时运动。
- 验收：静止时稳定，移动和转角时连贯；多次更新不会反复重置或闪烁，过期状态仍清晰。

## 3. 家具与区域分割、位置文字描述

- 对俯视场景中的家具、功能区域及可行走区域进行分割和命名，允许按实际场景确认或修正。
- 根据当前位置与区域/家具的关系输出文字，例如“沙发前”“家门口”“桌子旁”。
- 区域几何与定位地图绑定；在区域交界和定位抖动时避免描述频繁来回切换，无法确定时明确表示不确定。
- 验收：真实位置与文字区域描述一致，可供 App 及后续照料助手读取；家具或地图调整后可更新。

## 4. 用户端卡通风格俯视图

- 用户端考虑采用卡通风格俯视图，替代真实点云纹理的直接展示。
- 卡通图保留确认过的房间轮廓、家具和区域布局，与定位坐标严格对应；视觉风格变化不能导致几何错位。
- 保留真实点云底图作为调试和复核依据。卡通风格图也可复用第三项的分割与语义数据。
- 验收：卡通图、原始底图与实时点的位置对应一致，主要家具和区域清晰可辨。

以上四项为后续需求，具体实现方案与发布安排另行确定。
